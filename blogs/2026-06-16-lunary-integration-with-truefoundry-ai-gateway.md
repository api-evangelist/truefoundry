TrueFoundry's AI Gateway integrates with Lunary, an LLM observability platform, to enable structured tracing of model requests through OpenTelemetry. The setup adds roughly 3-4 ms of latency while handling 350+ RPS on a single vCPU, letting teams monitor prompts, token usage, and agent hierarchies in Lunary's dashboard.
