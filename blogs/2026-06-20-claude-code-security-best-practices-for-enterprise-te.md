Outlines security best practices for deploying Claude Code in enterprises, emphasizing eliminating shared API keys in favor of SSO-based authentication, user-level attribution through an AI Gateway, and governance of MCP server access. TrueFoundry's AI Gateway and MCP Gateway are presented as a centralized control plane for routing all Claude Code traffic with audit logs, cost controls, and access restrictions.
