TrueFoundry announced integration of Resemble AI with its AI Gateway, bringing voice cloning and text-to-speech capabilities into a unified platform for managing LLM and agent traffic. Teams can now route Resemble AI requests through TrueFoundry's gateway using native SDK pass-through, enabling centralized authentication, access control, and unified cost tracking. The integration preserves Resemble's full API surface without forcing it into an OpenAI-compatible format, allowing requests to Resemble's /synthesize and /stream endpoints to flow through the gateway path.
