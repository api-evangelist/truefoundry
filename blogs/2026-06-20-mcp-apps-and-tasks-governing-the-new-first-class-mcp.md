The MCP 2026-07-28 release introduces MCP Apps (server-rendered UI in sandboxed iframes) and Tasks (long-running work as durable state machines) as first-class extensions, creating new governance surfaces. TrueFoundry's MCP Gateway is positioned as the control point to screen app content through output guardrails, enforce role-based access, and trace task lifecycles to prevent runaway costs.
